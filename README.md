# 📱 WhatsApp Automation Bot

## 🚀 Overview
A simple desktop application built with Python using Tkinter for GUI and Selenium for automation.  
The app allows users to send WhatsApp messages easily using either a phone number or a contact name.

---

## ✨ Features
- Send message using phone number  
- Send message using contact name  
- Simple and user-friendly interface  
- Uses Chrome profile (no need to scan QR every time)  
- Automated sending using Selenium  

---

## 🛠️ Technologies Used
- Python  
- Tkinter  
- Selenium  
- ChromeDriver
